Sources. Official trophy names, descriptions and grades are as PlayStation publishes them, as listed by Exophase and PSNProfiles, the two agreeing. Each guide is written in our own words from the official description and cites its sources beside it; where the description states no location, step or target, the guide says so instead of inventing one.

Missable means story-gated. A trophy is flagged missable only where its official description ties it to one story chapter or mission, or to a choice made once — the reason is written inside its guide. Everything else can be earned at any time.

Unofficial fan guide, not affiliated with Rockstar Games or PlayStation. No logos, artwork or game screenshots are used. Progress is stored only in this browser (localStorage); export downloads a JSON file and import reads one back.
